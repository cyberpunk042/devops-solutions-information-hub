**Installer hardening:** `tools/assistant.py` now runs `_preflight_gateway_health()` at start of `cmd_install` and `cmd_uninstall`, detecting both failure modes (legacy key + version-managed Node path) and surfacing remediation. New flags `--skip-preflight` and `--auto-fix-gateway` on install.
