# Operator directive 2026-05-04 — new machine context load + possible project adaptation

## Verbatim

> "Lets gather a strong context. this is a new machine with a new root project /root but first we need to load into context this project knowledge. 30+ Operations go. we might need to adapt this project itself too since its a new system structure and type"

## Decomposition (without paraphrasing the directive itself)

- "Lets gather a strong context" — instruction to load context comprehensively.
- "this is a new machine with a new root project /root" — environment fact: new machine, root project at /root.
- "but first we need to load into context this project knowledge" — sequencing: load THIS project's knowledge before anything else.
- "30+ Operations go" — execute directive; minimum 30 operations.
- "we might need to adapt this project itself too since its a new system structure and type" — possibility flag, not yet a decision: adaptation may be needed.

## How to apply

- First action: `.venv/bin/python -m tools.gateway orient` (per SessionStart reminder).
- Behave FROM the project — use gateway/pipeline/view/stats/MCP catalog as the operating system.
- "30+ Operations" = execute, not propose. No probing `--help`, no asking which subset.
- Adaptation is a possibility the operator flagged — do not unilaterally change project files; surface findings, the operator decides.
- Words sacrosanct: do not collapse "we might need to adapt" into "we are adapting."
