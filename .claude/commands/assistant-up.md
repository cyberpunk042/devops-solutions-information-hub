# /assistant-up — Start the assistant

Starts the named Profile's assistant via systemd (preferred) or OpenClaw direct daemon. After this, the assistant is LIVE — operator can interact via OpenClaw channels (Slack/Discord/Telegram/CLI) and any wired surfaces (Multica board · Claude OS Memory MCP · wiki MCP · Claude Code ambient · etc.).

## Usage

```
/assistant-up <profile-name>
```

## Run

!`bin/assistant up $ARGUMENTS`
