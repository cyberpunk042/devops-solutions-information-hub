# Body-of-Work Distillation Pattern — Tier-2 Promotion Candidate Identification via Pareto Leverage

## Summary

The body at 123 pieces is operator-empirical territory for tier-2 promotion. Per /loop directive *"if one piece is ready for review you can move to the next"*: per-piece confirmation is operator-territory, but agent can SURFACE recommended-priority. Per Fire 88 minimum-viable-adoption: Pareto-optimal-subset captures 80% value with smallest piece-count. Per Fire 109 tier-elevation pathway: each piece elevation is 6-26h. Per Fire 119 foundational-cluster prioritization: cluster-coverage prioritization. This Fire 125 pattern applies Pareto to BODY-PIECES (not clusters): identify ~10-15 highest-leverage pieces from 123 whose tier-2 promotion captures ~80% of body's empirical value. The pattern specifies criteria + scoring + recommended subset + composability with Fire 109 elevation. Per /loop directive: this fire surfaces operator-review-ready candidate list.

## Pattern Description

### Pareto applied to body-of-work pieces

Per Fire 88 + general Pareto principle:
- 20% of pieces capture 80% of body's value
- 80% of pieces are supporting / specialized / forward-anchored

For the 123-piece body, Pareto-optimal subset is ~24-30 pieces (20-25% of body). Tier-2 promotion of THIS SUBSET FIRST gives maximum review-efficiency for operator + maximum elevation-leverage.

### Distillation criteria (per piece)

```
A piece scores HIGH-LEVERAGE if (each criterion 0-3 points; max 18):

CRITERION A: Substantive distinctness (0-3)
  0 = mostly redundant with other pieces
  1 = some unique contribution
  2 = substantively distinct
  3 = pivotal contribution to body methodology

CRITERION B: Cross-reference centrality (0-3)
  0 = referenced by 0-2 other pieces
  1 = referenced by 3-5
  2 = referenced by 6-10
  3 = referenced by 10+ (body's central node)

CRITERION C: Empirical evidence richness (0-3)
  0 = purely speculative; no evidence
  1 = evidence sparse (1-2 instances)
  2 = evidence moderate (3-5 instances)
  3 = evidence rich (5+ instances)

CRITERION D: Cross-project applicability (0-3)
  0 = /opt-only; no sister-project parallel
  1 = /opt + 1 sister-project
  2 = /opt + 2-3 sister-projects
  3 = ecosystem-wide (5 sister-projects)

CRITERION E: Stage of maturity (0-3)
  0 = T0 (no policy)
  1 = T1 (designed only)
  2 = T2 (partial implementation)
  3 = T3+ (full or higher)

CRITERION F: Operator-empirical evidence (0-3)
  0 = no operator-empirical input
  1 = single-mention operator-empirical confirmation
  2 = repeated operator-empirical (multiple sessions)
  3 = sacrosanct directive driver

Total: 0-18 points

Threshold for tier-2 promotion candidate: ≥12 points
Threshold for tier-2 PRIORITY candidate: ≥15 points
```

### Operator-review-efficient ordering

Per /loop directive *"30 pieces if not 70-80 pieces and changes... no lazyness... no rush"*: operator's 30-80-piece estimate matches Pareto-subset (15-19 pieces ≈ minimum end of operator's range).

Recommended operator-review order:
```
PHASE 1 (Pareto-priority — ~5 pieces):
  1. P1-P4 already-validated principles (foundation)
  2. Fire 65 substitution-pattern lesson (meta-frame)
  3. Fire 103 4-tier asymmetry audit (audit method)
  4. Fire 109 tier-elevation pathway (elevation method)
  5. Fire 93 + Fire 94 (C04 + C02 per-instance evidence)

PHASE 2 (Pareto-secondary — ~14 pieces):
  6. Fire 102 worked example #4 (real-session evidence)
  7. Fires 105+106+107 auto-compact triplet (defense-in-depth specs)
  8. Fire 90 sustained-feedback-loop pattern
  9. Fire 99 question-registry + Fire 101 blocker-impediment
  10. Fire 98 mode-by-nature
  11. C18 + C19 + C12 + C03 per-instance evidence (Fires 111+115+120+123)
  12. Decision-packages v4 + v5 (Fires 104+117)
  13. 100-piece + 120-piece milestone logs

PHASE 3 (extended Pareto — remaining ~8 pieces):
  Variable; per operator-empirical priority

PHASE 4 (full body 80+ pieces):
  Forward-anchored; operator-empirical
```

### Composability with Fire 109 tier-elevation

Per Fire 109: tier-elevation procedure 5-step per piece. This Fire 125 specifies WHICH pieces to elevate first:

```
Fire 109 + Fire 125 combined methodology:
  Step A: Apply Fire 125 distillation criteria → identify Pareto-priority pieces
  Step B: Apply Fire 109 5-step elevation per priority piece
  Step C: Re-audit per Fire 103 + Fire 114 — measure tier-distribution shift
  Step D: Confirm Fire 88 minimum-viable-adoption holds (80% value with 20% pieces elevated)
  Step E: Operator-empirical: ratify / refine / extend per Fire 121 re-loop triggers

Estimated effort:
  Phase 1 (5 pieces × 8-26h per Fire 109) = 40-130h
  Phase 2 (14 pieces × 6-15h per Fire 109) = 84-210h
  Combined: 124-340h for Pareto-priority + secondary
```

### Anti-patterns this pattern avoids

| Anti-pattern | Why bad | How avoided |
|---|---|---|
| Promote all 123 pieces equally | Operator-attention-overflow | Pareto-subset prioritization |
| Promote by chronological order | Recent ≠ highest-leverage | Score-based ranking |
| Promote by piece-author preference | Author-bias; not body-empirical | Multi-criterion scoring (6 dimensions) |
| Skip empirical evidence criterion | Speculation-pieces over-weighted | Criterion C explicit |
| Skip cross-project criterion | Sister-project blind | Criterion D explicit |
| Promote without verifying tier | T1-only pieces over-promoted | Criterion E explicit |
| Single-fire promotion of all priority | Operator-cycle overload | Phased recommended-ordering |

## When To Apply

Apply this body-of-work distillation pattern when:
- Body has 50+ pieces (sufficient density for distillation)
- Tier-2 promotion phase begun
- Operator-empirical efficiency matters (review limited to subset)
- Pareto investment desired (max-leverage with min-effort)
- Composability with Fire 109 elevation methodology needed

- Body has < 30 pieces (Pareto-subset = full body)
- All pieces operator-empirical-confirmed (distillation-redundant)
- Operator-explicit preference for full-body review
- Goldilocks: POC body where exhaustive review is feasible
