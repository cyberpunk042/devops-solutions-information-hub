### 4. The runtime loop

> ```text
> MAP -> SPEC -> TEST -> ACT -> EVAL -> COMMIT -> LEARN
> ```
> — dump 18316

This is the **runtime-tier** loop (per-request execution discipline), distinct from the wiki methodology engine's 5 universal stages (`document → design → scaffold → implement → test` — authoring-tier). The two are layered, not conflicting:

- The wiki methodology engine governs how we **author** wiki pages and code artifacts (P2 governance).
- The runtime loop governs how the workstation **executes** a request once the artifacts exist.

**Catalog binding**: MS048 (Goldilocks Scheduler) implements the routing layer that walks each request through MAP→SPEC→TEST→ACT→EVAL→COMMIT→LEARN; sovereign-os MS027 observability traces each stage transition; the cockpit displays loop state per active request.
